# Quintessential Digital — Website

Live domain: https://www.quintessentialdigital.com/

## Deploy on Render (Static Site)
1) Push these files to a GitHub repo (root).
2) In Render:
   - New + → Static Site
   - Connect the repo
   - Build Command: (leave empty)
   - Publish Directory: `.`
3) Deploy.

## Custom domain
Render → Site → Settings → Custom Domains
- Add: www.quintessentialdigital.com
- Add: quintessentialdigital.com (optional, redirect to www)

Render will show the DNS records to add in your domain provider.
